Trae 账号信息一键采集并推送（Mac 免配置版）
================================================

用途
----
在「已登录目标账号的 Trae / TraeWork 桌面客户端」的 Mac 上，
一键采集 RefreshToken 和设备指纹，并自动写回飞书多维表格。
免安装、免配置环境：使用系统自带 python3，
缺 AES 库自动走 openssl 兜底，缺 requests 自动走标准库，无需 pip 安装。

首次使用
--------
1. 确认包内有 feishu_config.json（管理员分发时通常已放好）
   没有的话：把 feishu_config.example.json 复制一份，改名
   feishu_config.json，填入 4 个参数
2. 双击「一键采集.command」
   - 若提示「未验证的开发者」：终端执行
     xattr -d com.apple.quarantine 一键采集.command 后再双击
   - 若提示没有执行权限：终端执行
     chmod +x 一键采集.command

日常使用
--------
1. 双击「一键采集.command」
2. 脚本自动采集并按「用户ID」写回飞书表格对应行：
   - 已有该账号的行：直接覆盖刷新凭证
   - 新账号：自动新建一行
3. 窗口会输出本账号的用户ID；新账号如需人名，
   可在表格中把账号名称改成对应人名
4. 完成后每天 GitHub Actions 会自动按表格里的凭证签到

Token 失效时
-----------
飞书签到卡片标红某账号时，让该账号的主人双击运行一次
「一键采集.command」即可恢复，无需任何其他操作。

注意事项
--------
1. 首次运行若提示安装"命令行开发者工具"，按系统弹窗安装即可
   （或终端执行 xcode-select --install）
2. 脚本自动取「最近使用」的客户端登录态；如本机登录了多个不同账号，
   先确认目标账号的客户端是最近使用的那个，或临时退出其他客户端。
   需要查看本机所有客户端登录态时，可在终端运行：
   python3 collect_account_info.py --list
3. RefreshToken 会被客户端续期或重登顶掉（约 1~2 周一次，属正常现象），
   看到签到卡片提示失效后重跑一次本脚本即可。
4. 输出包含敏感凭证，仅写入自己的多维表格，请勿外传。
5. 本包文件均为 UTF-8 编码，Mac 原生格式，可直接用文本编辑器查看。
