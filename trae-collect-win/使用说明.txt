Trae 账号信息一键采集（Windows 免安装版）
================================================

用途
----
在「已登录目标账号的 Trae / TraeWork 桌面客户端」的 Windows 电脑上，
一键采集 RefreshToken 和设备指纹，并直接写入飞书多维表格「账号列表」。
免安装：自带便携版 Python，双击即可运行，无需配置任何环境。

首次使用前：替换「一键采集.bat」里的 4 个配置
------------------------------------------------
右键「一键采集.bat」→ 编辑（或用记事本打开），
把以下 4 行中的 TOFILL 换成真实值：

| 要替换的配置 | 去哪里获取 |
|--------------|-----------|
| FEISHU_APP_ID | 飞书开放平台 https://open.feishu.cn/app → 进入你创建的自建应用 → 凭证与基础信息 → App ID（cli_ 开头） |
| FEISHU_APP_SECRET | 同上页面的 App Secret |
| FEISHU_BITABLE_APP_TOKEN | 多维表格 URL 中 /base/ 后面那串字符，如 https://my.feishu.cn/base/xxxxxx 中的 xxxxxx |
| FEISHU_BITABLE_ACCOUNT_TABLE | 「账号列表」表的 table_id：在飞书中打开账号列表 → 浏览器地址栏 URL 中 table=tblxxx 的 tblxxx |

同时把 ACCOUNT_NAME 改成要采集的账号名称。

日常使用
--------
双击「一键采集.bat」即可。看到「已更新多维表格账号」或
「已新建多维表格账号」即为成功，之后每天 GitHub Actions 会自动用它签到。

注意事项
--------
1. 账号名称与多维表格「账号列表」中的名称「完全相等」才会覆盖同名行
   （区分大小写），不相等会新建一行。
   例如表格里是「张增辉的traeCode」，就必须填一模一样的「张增辉的traeCode」，
   写成「张增辉的TraeCode」会追加成新的一行。
2. 多台客户端登录态：脚本自动取「最近使用」的客户端；如本机登录了多个
   不同账号，先确认目标账号的客户端是最近使用的那个，或临时退出其他客户端。
3. RefreshToken 有效期约 6 个月，过期后重新在客户端登录并再跑一次本脚本即可。
4. FEISHU_APP_SECRET 是敏感凭证：填写后的 bat 不要发给他人，
   也不要上传到公开仓库（本目录已脱敏，可安全入库）。
