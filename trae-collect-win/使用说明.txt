Trae 账号信息一键采集并推送（Windows 免安装版）
================================================

用途
----
在「已登录目标账号的 Trae / TraeWork 桌面客户端」的 Windows 电脑上，
一键采集 RefreshToken 和设备指纹，并自动写回飞书多维表格。
免安装、免配置环境：自带便携版 Python。

首次使用（一次性）
------------------
1. 把本目录中的 feishu_config.example.json 复制一份，
   重命名为 feishu_config.json
2. 用记事本打开 feishu_config.json，填入 4 个参数：
   FEISHU_APP_ID / FEISHU_APP_SECRET /
   FEISHU_BITABLE_APP_TOKEN / FEISHU_BITABLE_ACCOUNT_TABLE
   （由管理员统一提供，所有人填同一组值）
3. feishu_config.json 含密钥，请勿外传

日常使用
--------
1. 双击「一键采集.bat」
2. 脚本自动采集并按「用户ID」写回飞书表格对应行：
   - 已有该账号的行：直接覆盖刷新凭证
   - 新账号：自动新建一行
3. 窗口会输出本账号的用户ID；新账号如需人名，
   可在表格中把账号名称改成对应人名
4. 完成后每天 GitHub Actions 会自动按表格里的凭证签到

Token 失效时
-----------
飞书签到卡片标红某账号时，让该账号的主人双击运行一次
「一键采集.bat」即可恢复，无需任何其他操作。

注意事项
--------
1. 脚本自动取「最近使用」的客户端登录态；如本机登录了多个不同账号，
   先确认目标账号的客户端是最近使用的那个，或临时退出其他客户端。
   需要查看本机所有客户端登录态时，可在命令行中运行：
   python\python.exe collect_account_info.py --list
2. RefreshToken 会被客户端续期或重登顶掉（约 1~2 周一次，属正常现象），
   看到签到卡片提示失效后重跑一次本脚本即可。
3. 输出包含敏感凭证，仅写入自己的多维表格，请勿外传。
4. 「一键采集.bat」为 GBK（ANSI）编码，是中文 Windows 原生格式，
   双击即可正常运行；请勿用编辑器把它转存为 UTF-8，
   否则运行时中文提示会乱码、命令会执行失败。
