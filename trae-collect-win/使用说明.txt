Trae 账号信息一键采集（Windows 免安装版）
================================================

用途
----
在「已登录目标账号的 Trae / TraeWork 桌面客户端」的 Windows 电脑上，
一键采集 RefreshToken 和设备指纹。
免安装、免配置：自带便携版 Python，双击即可运行。

使用步骤
--------
1. 双击「一键采集.bat」
2. 窗口会输出 5 个值：
   RefreshToken / 用户ID / 设备ID / 机器ID / 客户端版本
3. 打开飞书多维表格「账号列表」，把 5 个值粘贴到对应列：

   | 输出项       | 粘贴到表格中的列 |
   |--------------|------------------|
   | RefreshToken | RefreshToken     |
   | 用户ID       | 用户ID           |
   | 设备ID       | 设备ID           |
   | 机器ID       | 机器ID           |
   | 客户端版本   | 客户端版本       |

   - 已有该账号的行：双击那一行逐列粘贴，并把该行 Cookie 列清空
     （改走 RefreshToken 模式）
   - 新账号：先新增一行填「账号名称」，再粘贴 5 个值，「启用」列打勾

4. 完成后每天 GitHub Actions 会自动按表格里的凭证签到

注意事项
--------
1. 脚本自动取「最近使用」的客户端登录态；如本机登录了多个不同账号，
   先确认目标账号的客户端是最近使用的那个，或临时退出其他客户端。
   需要查看本机所有客户端登录态时，可在命令行中运行：
   python\python.exe collect_account_info.py --list
2. RefreshToken 有效期约 6 个月，过期后重新在客户端登录并再跑一次本脚本即可。
3. 输出包含敏感凭证，仅粘贴到自己的多维表格，请勿外传。
4. 「一键采集.bat」为 GBK（ANSI）编码，是中文 Windows 原生格式，双击即可正常运行；
   请勿用编辑器把它转存为 UTF-8，否则运行时中文提示会乱码、命令会执行失败。
